# 스마트 자리바꾸기 (Smart Class Seat Arranger)

선생님을 위한 맞춤형 학급 자리 바꾸기 및 A4 인쇄 프로그램입니다. 다양한 교실 배열(3분단 짝꿍, 5행 5열 일렬 등)을 지원하며, 이전 짝·이전 자리 피하기, 앞자리 배려, 특정 학생 분리 등 다양한 교육적 요구를 고려하여 공정하고 편리하게 자리를 배치합니다.

---

## 🌟 주요 기능

### 1. 다양한 교실 좌석 배열 (Layouts)
- **3분단 짝지어 앉기 (2-2-2)**: 6열 분단형 표준 교실 배치
- **5행 5열 일렬 한줄로 앉기**: 1인 1석 독립형 배치 (시험, 자습, 독서실형)
- **4분단 짝지어 앉기 (2-2-2-2)**: 8열 넓은 교실형 배치
- **자유 맞춤 설정 (Custom)**: 행(2~10)과 열(2~12), 짝꿍 그룹 크기, 복도 위치 직접 조절
- **원클릭 책상 켜기/끄기**: 비어 있는 책상이나 장애물 위치를 클릭 한 번으로 활성화/비활성화하여 irregular 교실 형태도 완벽 대응

### 2. 배치 시 주의 사항 및 조건 설정 (Constraints & Rules)
- **이전 같은 자리 피하기**: 직전 회차/과거 배치에서 앉았던 동일 좌석을 피해 다른 위치로 순환
- **이전 짝 피하기**: 과거 배치 이력을 조회하여 이미 짝이었던 학생과의 중복 매칭 방지
- **짝꿍 성별 규칙**: 성별 무관(자유) / 남녀 짝 우선 / 동성 짝 우선 선택
- **앞자리 배려 학생 우선석**: 시력·청력·수업 집중 배려가 필요한 학생을 칠판 앞 1~2열에 우선 배정
- **특정 학생 분리 배치**: 서로 장난을 많이 치거나 갈등이 있는 학생 쌍을 지정하여 인접 좌석 분리
- **고정석 지정**: 특정 학생을 원하는 책상에 고정(Pin)한 후 나머지 학생들만 셔플

### 3. 교실 TV/프로젝터용 추첨 애니메이션
- 학생들과 함께 보며 즐길 수 있는 슬롯머신 롤링 애니메이션
- Web Audio API 기반 효과음 및 완료 팡파르
- 확정 시 화면 가득 터지는 축하 컨페티(폭죽) 효과

### 4. 고해상도 A4 인쇄 및 출력
- 브라우저 인쇄(`Ctrl+P` / `window.print()`) 최적화 레이아웃 (`@media print`)
- **시점 선택**:
  - **칠판 기준 (학생 시선)**: 칠판이 상단에 위치
  - **교탁 기준 (선생님 시선)**: 교탁에 서서 교실을 바라보는 시선과 좌우 일치
- **학번순 학생 좌석 번호 일람표**: 좌석표 하단에 출석부 순서대로 좌석 번호가 정리되어 게시판 부착 및 출결 확인에 유용
- **흑백 잉크 절약 모드**: 선명한 고대비 테두리로 흑백 프린터에서도 또렷하게 인쇄

### 5. 프라이버시 & 데이터 보호
- 모든 학생 명단 및 배치 이력은 브라우저 내부(`LocalStorage`)에만 안전하게 보관됩니다.
- 외부 서버로 학생 개인정보가 전송되지 않아 안심하고 사용할 수 있습니다.
- 엑셀 및 나이스(NEIS) 형식 명단 직접 붙여넣기 및 CSV 내보내기 지원
